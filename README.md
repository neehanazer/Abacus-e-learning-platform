# Abacus E-Learning Platform 🧮

A modern, interactive, and child-friendly E-Learning platform designed for mastering Abacus mental arithmetic and Soroban techniques.

## ✨ Key Features

- **Module 1: Authentication & Dashboard**: Personalized student profiles, star tracking, daily practice streak, and quick progress metrics.
- **Module 2: Learning Hub**:
  - 📖 **8-Level Syllabus**: Comprehensive curriculum spanning Level 1 through Level 8 (Direct single-digit, Small Friends, Big Friends, Multi-row continuous calculations, Multiplication, Division).
  - 🎥 **Video Lessons**: Curated lessons with video player, lesson transcripts, Sensei tips, and star rewards.
  - 🧮 **Practice Module**: 20-question randomized worksheets, interactive Soroban bead representations, vertical math columns, and immediate feedback.
  - 📝 **Homework Module**: Assigned homework worksheets connected to lessons with pre-submission reviews, multi-attempt tracking, Sensei evaluation notes, and custom assignments.

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: Tailwind CSS & Vanilla CSS Design System
- **Animations**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React
- **State Management**: React Context & LocalStorage Persistence

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the platform.
